# 资源纳管模块产品需求设计说明书 V2.0

版本：V2.0 模块化评审稿  
整理日期：2026-09-15  
所属产品：知识工程平台  
适用对象：产品、业务负责人、交互设计、研发、测试、实施、安全与运维人员  
文档状态：基于现行业务口径、当前原型和前期需求讨论重新编排；新增细化规则仍需评审确认。

## 1. 版本说明

### 1.1 本版核心调整

本版在第一版基础上完成三项结构性调整：

1. 文件中心不再设置企业空间、团队空间、个人空间下级入口。文件中心是统一文件工作台，按知识源查看和管理已接入文件。
2. 团队空间和个人空间只在资源目录管理中区分。空间代表资源的组织、协作和权限范围，不作为文件中心的分类层级。
3. 元数据标准管理暂时从资源纳管功能范围、菜单、流程和验收中移除。文件仍保留业务属性、管理属性、标签补充和人工确认能力，但本期不提供独立的标准定义、模板和应用规则管理页面。

### 1.2 本版内容组织方式

本版按照产品模块编排。每个模块尽量使用统一结构：模块定位、使用角色、页面构成、核心功能、业务流程、业务规则、状态、权限、异常、模块输出和验收要求。跨模块规则集中放在文档后半部分，避免同一规则散落在多个章节。

### 1.3 需求依据标识

| 标识 | 含义 |
| --- | --- |
| 已明确 | 已在前期业务讨论或现行产品口径中确定，后续设计应保持一致 |
| 当前原型 | 当前静态页面或脚本已经表达，但不代表后端、鉴权和持久化已经实现 |
| 设计补充 | 为形成完整产品闭环新增的建议，需在研发前评审确认 |

### 1.4 当前验证边界

本说明书基于工作区文档、页面结构和交互脚本整理。当前原型主要使用静态数据、浏览器本地存储和模拟任务，不等于已经具备真实连接器、共享持久化、服务端权限、任务调度、审计、性能和容灾能力。静态检查、页面可访问或 JavaScript 语法通过，也不能替代浏览器交互、接口、数据库、真实来源和权限验收。

## 2. 产品定位与范围

### 2.1 模块定位（已明确）

资源纳管负责将企业可授权使用的原始知识资源统一接入平台，完成资源登记、来源追踪、内容版本管理、属性与标签补充、资源目录组织、协作权限管理和任务过程追踪，为知识生产提供可识别、可访问、可追溯的原料。

平台主链路为：

`知识源接入 → 文件／数据表／原始图数据登记 → 属性与标签补充 → 资源目录组织 → 知识生产 → 知识库／语义知识图谱发布 → 知识服务`

资源纳管中的文件、数据表和原始图数据是原始资源。知识管理中的正式知识资产只有知识库和语义知识图谱。资源经过纳管并不自动成为知识资产。

### 2.2 业务目标

| 业务问题 | 产品目标 | 结果表现 |
| --- | --- | --- |
| 资源散落在多个业务系统 | 统一登记知识源和资源 | 可按来源查询、追踪和处理异常 |
| 同一文件被多次复制管理 | 资源身份与目录挂载分离 | 同一资源可被多个目录引用，不产生重复内容 |
| 文件缺乏业务描述 | 自动补充属性和标签，并由人工确认 | 可按业务特征查找和选择资源 |
| 资源组织方式和协作范围不清 | 用团队空间和个人空间承载目录、成员与权限 | 能解释资源位于哪里、由谁管理、谁可以访问 |
| 批量接入和自动处理不可见 | 任务中心统一记录执行过程和结果 | 可查看进度、失败原因、逐文件结果和待确认项 |
| 资源更新后下游知识过时 | 保存资源版本和下游引用 | 能提示受影响的知识生产任务和知识资产 |
| 标签、目录和权限概念混用 | 分离描述、组织和授权 | 标签变更不移动资源，目录挂载不自动扩大权限 |

### 2.3 功能范围

资源纳管包含以下一级功能模块：

| 顺序 | 模块 | 核心职责 |
| --- | --- | --- |
| 1 | 资源概览 | 查看资源规模、接入状态、待处理事项和治理质量 |
| 2 | 文件中心 | 按知识源统一查看和管理文件，不区分企业、团队、个人空间 |
| 3 | 资源目录管理 | 通过团队空间、个人空间组织资源并管理协作权限 |
| 4 | 数据表 | 按结构化数据源管理表、视图和字段结构 |
| 5 | 图数据 | 管理接入的原始节点、边和属性数据 |
| 6 | 标签管理 | 聚合文件标签、管理分类和查看关联文件 |
| 7 | 任务中心 | 管理文件上传、知识源同步、属性与标签补充、自动入目任务 |
| 8 | 知识源管理 | 配置连接器实例、访问模式、接入范围和运行状态 |

### 2.4 本期不包含的能力

- 不设置资源发布、取消发布、资源上架或资源审核发布流程。
- 文件属性和标签确认只确认资源描述，不发布资源，也不发布知识资产。
- 自动入目确认只建立资源与目录的挂载关系，不触发知识资产发布。
- 原始图数据接入不等于构建语义知识图谱。
- 知识源连接成功不等于文件已同步，更不等于知识库已创建。
- 不在文件中心设置企业空间、团队空间、个人空间。
- 不建立与资源目录平行的空间业务对象。
- 本期不提供元数据标准管理、属性模板管理、属性应用规则或标准版本管理。

## 3. 总体信息架构

### 3.1 导航结构

```text
资源纳管
├── 资源概览
├── 文件中心
├── 资源目录管理
│   ├── 团队空间
│   └── 个人空间
├── 数据表
├── 图数据
├── 标签管理
├── 任务中心
└── 知识源管理
```

文件中心为一级页面，不展开空间子菜单。资源目录管理是唯一需要展开团队空间和个人空间的模块。

### 3.2 模块之间的关系

| 来源模块 | 产生对象 | 被哪些模块使用 |
| --- | --- | --- |
| 知识源管理 | 知识源实例、连接状态、接入范围 | 文件中心、数据表、图数据、任务中心 |
| 文件中心 | 文件资源及版本 | 资源目录、标签、任务中心、知识生产 |
| 数据表 | 表／视图资源及结构版本 | 资源目录、任务中心、知识生产 |
| 图数据 | 节点集／边集资源及结构版本 | 资源目录、任务中心、知识生产 |
| 资源目录 | 空间、目录节点、资源挂载、目录授权 | 资源查找、知识生产选材、权限判断 |
| 标签管理 | 标签及文件关联 | 文件筛选、目录整理、知识生产选材 |
| 任务中心 | 执行记录、逐项结果、确认记录 | 各资源模块和通知中心 |
| 资源概览 | 聚合指标和治理待办 | 管理人员下钻到对应模块 |

### 3.3 核心概念边界

- 知识源说明资源来自哪里、如何访问和更新。
- 文件中心、数据表和图数据说明平台已经登记了哪些原始资源。
- 资源目录说明资源如何组织、由谁负责、谁可以协作和访问。
- 属性和标签说明资源是什么、适用于什么业务。
- 任务中心说明系统正在处理什么、处理到哪里、哪些结果需要人工确认。
- 知识生产使用资源纳管的确定资源版本，但不在本模块内完成知识库或图谱发布。

## 4. 公共业务对象

### 4.1 对象定义

| 对象 | 定义 | 关键关系 |
| --- | --- | --- |
| 连接器类型 | 某类外部系统的接入能力定义 | 一个类型可创建多个知识源实例 |
| 知识源实例 | 特定系统地址、凭据、访问模式和接入范围的配置 | 一个实例产生多个资源 |
| 资源 | 平台登记的一份文件、表、视图、节点集或边集合 | 具有稳定资源 ID 和多个版本 |
| 资源版本 | 某一时点的内容或结构快照 | 绑定解析、属性、标签、确认和下游引用 |
| 团队空间 | 团队共同维护的资源目录根节点及其协作范围 | 有负责人、成员、权限和子目录 |
| 个人空间 | 当前用户管理的资源目录根节点 | 默认由本人管理，可按资源单独授权 |
| 目录节点 | 团队或个人空间中的层级组织节点 | 可挂载多个资源并继承权限 |
| 资源挂载 | 资源与目录节点的引用关系 | 移除挂载不删除资源 |
| 属性结果 | 系统、AI、规则或人工为某资源版本形成的描述值 | 区分建议、草稿和已确认值 |
| 标签 | 对文件业务特征的简短描述 | 与文件资源多对多关联 |
| 任务 | 一次批处理或单项处理的执行记录 | 包含多个任务项 |
| 任务项 | 任务对某一资源版本的处理记录 | 保存状态、结果、错误和审核信息 |
| 授权记录 | 主体对目录或资源的操作权限 | 支持用户、用户组、组织和继承来源 |
| 下游引用 | 知识生产或知识资产对资源版本的使用关系 | 用于影响分析和证据追溯 |

### 4.2 通用对象规则

1. 资源名称可修改，资源 ID 保持稳定。文件名不能作为跨页面和跨任务的唯一标识。
2. 远端资源建议使用“知识源 ID＋远端对象 ID”识别；本地上传生成平台资源 ID。
3. 同名但来源不同的资源是不同资源。同内容文件可以提示重复，但不能跨权限范围自动合并。
4. 内容或结构发生变化生成新资源版本；修改名称、标签、目录位置不生成内容版本。
5. 同一资源可以挂载到多个目录，所有目录引用同一资源身份和版本体系。
6. 文件中心不保存空间分类。资源属于哪个团队空间或个人空间，由资源目录挂载关系表达。
7. 业务属性、管理属性和标签都绑定到准确资源版本。新版本不能直接继承旧版本“已确认”状态。

## 5. 模块一：资源概览

### 5.1 模块定位

资源概览面向资源管理员、来源负责人和治理负责人，提供资源纳管运行态势、异常和待办入口。它是聚合看板，不承担资源编辑和任务处理。

### 5.2 页面构成

1. 核心指标区：资源总量、今日新增、接入成功率、待确认文件、属性完整度、异常知识源。
2. 资源类型分布：文件、数据表、图数据分别统计。
3. 接入运行情况：按知识源类型和实例显示正常、同步中、异常、停用。
4. 最近活动：展示上传、同步、属性与标签确认、自动入目等最近事件。
5. 治理待办：缺少关键属性、长时间待确认、解析失败、权限缺失、源端失效。
6. 快捷下钻：进入带有对应筛选条件的文件中心、任务中心或知识源管理。

### 5.3 指标口径

| 指标 | 计算规则 |
| --- | --- |
| 资源总量 | 当前有效且用户有权查看的去重资源 ID 数；版本和多目录挂载不重复计算 |
| 今日新增 | 按租户时区计算，当日首次登记的资源数量 |
| 接入成功率 | 周期内成功结束的接入任务项数／已结束接入任务项数 |
| 待确认文件 | 当前版本存在属性或标签结果且尚未确认的文件数 |
| 属性完整度 | 已填写且通过基础校验的适用字段数／当前要求填写的字段数 |
| 异常知识源 | 当前为认证失败、连接异常或连续同步失败的来源实例数 |
| 解析成功率 | 周期内解析成功文件数／已结束解析文件数 |

本期没有元数据标准管理，属性完整度按照产品内置字段及当前文件类型的适用字段计算。后续如重新引入标准管理，再迁移至可配置口径。

### 5.4 业务规则

- 文件、数据表和图数据分别统计，不将表行数或图节点数加入资源总量。
- 指标、趋势和导出均先执行权限过滤，不泄露无权资源的数量。
- 分母为零时显示“不适用”，查询失败显示“未获取”，不能统一显示为 0。
- “已完成加工”属于知识生产指标。如保留在概览中，必须注明来自知识生产，不能与文件解析完成混用。
- 每个指标显示统计时间和统计口径；点击后进入对应模块并保留筛选条件。
- 最近活动使用业务事件，不用前端动画或模拟进度作为执行事实。

### 5.5 异常和空状态

- 无任何资源：显示创建知识源和上传文件入口。
- 当前账号无可见资源：说明暂无可访问内容，不显示全平台总量。
- 聚合服务失败：显示加载失败和重试，不渲染一组 0。
- 指标更新时间超过约定周期：显示数据延迟提示。

### 5.6 模块输出

- 用户可见范围内的资源指标快照。
- 异常来源清单和治理待办清单。
- 带筛选条件的模块下钻链接。
- 权限过滤后的概览报告。

### 5.7 重点验收

- 同一资源挂载多个目录，资源总量只增加一次。
- 低权限用户看不到无权资源的名称、数量和活动。
- 点击待确认数量后，文件中心或任务中心只显示相同口径的待确认文件。
- 聚合失败与真实零数据有不同反馈。

## 6. 模块二：文件中心

### 6.1 模块定位（已明确）

文件中心统一管理平台已经登记的文档类资源。页面按知识源筛选文件，不设置企业空间、团队空间和个人空间。团队或个人的组织归属由资源目录管理表达。

### 6.2 使用角色

| 角色 | 主要操作 |
| --- | --- |
| 资源管理员 | 查看全部授权来源、上传文件、处理异常、发起批任务 |
| 知识源负责人 | 查看负责来源的文件和同步结果 |
| 业务专家／资源负责人 | 核对文件属性、标签和适用信息 |
| 普通查看用户 | 按授权查找、预览和下载文件 |
| 知识工程师 | 选择可加工的资源版本进入知识生产 |

### 6.3 页面结构

文件中心采用左侧知识源、右侧文件列表的双栏工作台：

- 左侧展示“全部知识源”和已经配置的文档类知识源实例，支持搜索知识源。
- 右侧展示当前选中来源下的文件，支持搜索、状态筛选、标签筛选和时间筛选。
- 左侧固定提供“本地上传”知识源；选中后，右侧显示“上传文件”入口并支持选择各种文件。新建外部知识源仍从左侧来源区域发起。
- 已配置的外部知识源在节点功能组中提供“修改配置”，可维护连接信息、凭据、接入方式、同步范围和同步频率。
- 选中来源后，同步更新页面标题、来源说明、结果总数、列表和空状态。

### 6.4 文件列表

| 字段 | 含义与规则 |
| --- | --- |
| 文件名称 | 显示名称，点击进入文件详情；不能作为唯一键 |
| 类型 | PDF、DOCX、Markdown、Wiki 等真实格式或来源对象类型 |
| 知识源 | 来源实例名称；本地上传显示“本地上传” |
| 标签摘要 | 最多展示若干已生效标签，其余使用数量表示 |
| 当前版本 | 平台当前资源版本或远端修订映射 |
| 处理状态 | 列表主状态，底层解析、补充和确认状态分开保存 |
| 创建人／来源作者 | 本地上传显示上传者；远端资源显示可获得的源端作者 |
| 更新时间 | 默认使用内容当前版本更新时间，并提供字段解释 |

文件列表不设置“操作”列；文件名称是进入详情的统一入口。默认按更新时间倒序。列表总数必须与权限过滤及当前筛选一致。空状态区分：来源无文件、筛选无结果、来源未同步、来源异常和查询失败。

### 6.5 上传文件流程

1. 用户选择“本地上传”知识源，点击上传文件并选择一个或多个本地文件。
2. 系统展示文件名、类型、大小、重复提示和逐项移除入口。
3. 用户确认上传；服务端重新校验文件类型、大小、数量、存储配额和上传权限。
4. 系统创建文件上传任务和逐文件任务项。
5. 上传成功的文件生成资源 ID 和初始版本，进入解析及后续处理；失败文件保留原因并允许单项重试。
6. 用户可离开页面，任务继续执行；文件中心和任务中心均可查看结果。

同名文件不能直接覆盖。系统需要让用户明确选择“作为新文件”或“更新已有文件”。更新已有文件必须校验目标文件编辑权，并生成新版本。

本地上传文件只显示为“本地上传”来源，不附带企业、团队或个人空间属性。上传后如需进入团队或个人组织范围，用户在资源目录中添加该资源。

### 6.6 文件详情

文件中心只有一种通用文件详情，重点展示资源本身，不展示“所属企业空间／团队空间／个人空间”。页面包含：

1. 基本信息：资源名称、编码、类型、大小、知识源、源端文件 ID、版本、创建／登记时间、更新时间和负责人；不展示“来源系统”和“语言”。
2. 文件预览：在权限允许和格式支持时展示当前版本正文或预览。
3. 文件摘要：标明系统生成或人工填写，不冒充原文。
4. 业务属性：业务描述、业务域、业务分类、使用场景等产品内置字段。
5. 管理属性：责任部门、资源负责人、密级、共享范围、生命周期和有效期等产品内置字段。
6. 标签：已确认标签、待确认建议及人工补充入口。
7. 版本记录：版本号、来源修订、更新时间、变更人和处理状态。
8. 目录引用：建议只读展示该资源已挂载的、有权查看的目录路径；目录权限维护在资源目录中完成。

文件中心详情不提供目录成员或目录权限管理。资源目录中的资源详情可以增加当前目录权限上下文，两者应使用资源 ID 和目录 ID 区分路由上下文。

### 6.7 属性、标签和证据

虽然本期移除元数据标准管理，文件仍需要属性补充与确认能力。字段暂由产品内置并由后端统一提供，前端不能各页面硬编码出互不一致的字段集合。

每个自动补充值至少保存：字段编码、建议值、来源方式、依据定位、处理任务、结果版本和确认状态。来源方式包括 AI 提取、AI 生成、系统匹配、规则判断和人工填写。

证据可以是页码、段落、表格位置、网页锚点、媒体时间段或源端字段路径。“查看原文”必须打开同一资源版本并定位到真实依据。无法定位时显示“暂无原文证据，请人工核对”，不能生成不存在的页码和引用。

共享范围、密级和责任部门等自动识别值只形成建议，不直接修改真实授权。技术事实如文件大小、类型和版本由系统生成，不允许 AI 推断覆盖。

### 6.8 保存与确认

- 保存修改：保存当前文件属性和标签草稿，不改变确认状态。
- 确认AI结果：文件详情页固定提供该按钮；存在待确认结果时可点击，校验必填字段、值类型、资源版本、结果修订号和用户权限后，使当前版本的AI属性与标签结果生效；已确认时按钮展示已确认状态并禁用。
- 文件列表不提供确认按钮或操作列，用户通过文件名称进入详情后核对、修改和确认。
- 已确认后修改：产生新草稿并回到待确认，原确认记录保留。
- 新内容版本到达：旧版本确认仍可追溯，新版本重新进入处理和确认。
- 任务详情和文件详情必须读取同一后端确认状态，不能分别保存两套状态。

### 6.9 文件操作

| 操作 | 业务规则 |
| --- | --- |
| 预览 | 每次请求校验资源查看权和内容可用状态 |
| 下载 | 建议作为独立内容权限；下载地址短期有效 |
| 重命名 | 修改平台显示名并保留历史名；远端资源默认不回写源系统 |
| 更新版本 | 生成新资源版本，不覆盖历史内容和证据 |
| 收藏 | 仅建立当前用户收藏关系，不改变权限和目录 |
| 分享 | 如本期保留，定义为对具体资源的授权，不产生文件中心空间分类 |
| 添加到目录 | 跳转或打开资源目录选择器，选择有权管理的团队／个人目录节点 |
| 删除文件 | 删除资源层对象，需要进行挂载和下游引用影响检查 |

重命名、移动本地文件夹、收藏、分享和删除等低频动作进入“更多”。“从目录移除”与“删除文件”是两个不同动作，文件中心不提供含糊的统一删除。

### 6.10 文件处理状态

底层建议拆分以下状态，列表可以组合成一个主要状态展示：

| 状态维度 | 状态 |
| --- | --- |
| 内容状态 | 可用、来源不可达、源端已删除、已逻辑删除 |
| 解析状态 | 待解析、解析中、解析成功、解析失败、格式不支持 |
| 属性与标签补充 | 待处理、处理中、处理成功、处理失败 |
| 人工确认 | 不适用、待确认、草稿、已确认、结果过时 |

### 6.11 权限规则

- 文件中心列表、搜索、预览、下载、导出和统计都执行服务端资源权限过滤。
- 用户能进入文件中心，不代表能够查看所有文件。
- 目录管理员不因管理某个目录自动获得所有挂载资源的编辑权。
- 自动识别的共享范围不能转换为授权记录。
- 用户被撤权后，旧页面、旧下载链接、搜索索引和后台任务均不得继续提供资源内容。

### 6.12 主要异常

| 异常 | 处理要求 |
| --- | --- |
| 不支持的文件格式 | 保留原资源，明确不支持解析，不生成虚假提取结果 |
| 扫描件无可用文本 | 显示缺少可解析正文；OCR 是否支持单独确认 |
| 同名文件 | 展示来源、资源 ID 和版本，要求用户明确选择 |
| 上传部分失败 | 成功项正常登记，失败项保留原因并可单项重试 |
| 确认时内容已更新 | 拒绝旧结果覆盖，提示重新处理或比较版本 |
| 两人同时编辑 | 通过修订号检测冲突，后提交者重新比较 |
| 无原文证据 | 允许有权用户人工填写并记录人工依据，不伪造证据 |
| 查询服务失败 | 显示加载失败和重试，不当作空列表 |

### 6.13 模块输出

- 文件资源及版本记录。
- 内容解析状态和预览结果。
- 属性、标签建议、草稿及确认结果。
- 文件上传任务和任务项。
- 对资源目录和知识生产可引用的稳定资源版本。

### 6.14 重点验收

- 文件中心侧栏或页面内不存在企业空间、团队空间、个人空间入口。
- 选择不同知识源时，标题、列表、数量和空状态同步更新。
- 文件详情不显示虚构的所属空间；目录引用只作关系展示。
- 同名上传不静默覆盖；更新已有文件生成新版本。
- 任务详情确认后，文件详情状态和标签同步变化。
- 整个文件流程不出现资源发布、已发布或取消发布。

## 7. 模块三：资源目录管理

### 7.1 模块定位（已明确）

资源目录管理用于按照团队协作和个人整理需求组织已经纳管的资源，并承载目录负责人、成员、继承权限和资源挂载关系。团队空间与个人空间只在本模块中区分。

资源目录不保存新的文件副本。目录中的文件、数据表或图数据都是对原资源的引用。

### 7.2 下级结构

| 下级入口 | 定位 | 主要用户 |
| --- | --- | --- |
| 团队空间 | 多人协作的目录根节点，管理成员和角色 | 团队负责人、目录管理员、编辑成员、查看成员 |
| 个人空间 | 当前用户自行整理资源的目录根节点 | 当前用户，以及被单项授权的协作者 |

### 7.3 团队空间列表

团队空间列表采用卡片形式，展示空间名称、可见范围、描述、目录数、资源数、负责人和更新时间。第一张“新建团队空间”卡片作为唯一创建入口，搜索框支持按名称和负责人筛选。

新建团队空间字段包括：

| 字段 | 规则 |
| --- | --- |
| 空间名称 | 必填；建议同一租户内唯一或按组织范围唯一 |
| 空间负责人 | 必填且为有效用户；自动成为管理成员 |
| 空间描述 | 必填，说明业务范围和资源用途 |
| 可见范围 | 全员可见、指定组织与成员、仅空间成员 |
| 管理成员 | 管理空间、目录、成员和权限 |
| 编辑成员 | 新建目录、添加和移除资源挂载 |
| 查看成员 | 浏览目录；查看资源时还需校验资源权限 |

创建空间与初始授权应在一个事务中完成，不能留下无负责人空间。移交负责人前必须选择有效接任人。

### 7.4 个人空间

个人空间由当前用户管理，支持新建文件夹、修改文件夹说明、重命名、删除文件夹、搜索目录、添加已有资源和调整目录。默认不向其他用户公开完整目录树。

每个本人创建的文件夹右侧设置一个统一功能按钮组，按固定顺序提供“新建、修改、重命名、删除”：

- 新建：在当前文件夹下创建子文件夹；同级名称不可重复。
- 修改：维护文件夹说明等基本信息，不改变名称、父级和文件内容。
- 重命名：只修改当前文件夹名称，不改变目录 ID、层级和文件归属。
- 删除：空文件夹直接进入确认；当文件夹下存在文件或子文件夹时，必须弹出二次确认弹窗，展示文件夹名称、子文件夹数量和文件数量，并明确说明将级联删除。

用户确认删除后，系统在同一事务或可回滚任务中删除当前文件夹、全部下级文件夹以及其中的全部文件。任一项删除失败时不得只保留部分结果；系统需要返回失败原因并保留完整目录。删除成功后刷新目录树、文件列表、数量统计和当前选中状态，并写入操作者、时间、目录、文件清单与结果的审计日志。

如果需要与他人协作，优先通过具体资源授权或将资源添加到有明确成员的团队空间。是否允许个人目录整体分享属于后续能力，不在本期默认范围。

个人空间不是个人文件上传仓库。上传动作仍在文件中心完成，个人空间通过“添加资源”选择文件中心已有资源。

### 7.5 目录工作台

目录工作台采用左目录树、右资源列表和权限区域的布局：

1. 左侧目录树支持展开、选中、搜索和显示祖先路径。
2. 右侧展示当前目录路径、描述、资源数量和资源列表。
3. 团队空间显示成员和权限摘要；个人空间显示当前用户管理提示。
4. 团队空间目录节点右侧功能组固定包含：修改、删除、移动、重命名，删除仅允许删除空目录；新建目录由页面对应入口承担。个人空间按 7.4 的独立规则，在同一功能组中提供新建、修改、重命名、删除，并允许二次确认后的级联删除。
5. 资源列表不设置“操作”列。资源名称作为统一入口：点击文件、数据表或图数据名称进入资源详情，点击文件夹名称进入下级目录。移动挂载、移除挂载等低频能力从资源详情或批量管理入口发起。

### 7.6 目录节点规则

- 同一父目录下名称不可重复，不同父目录可以重名。
- 新建子目录默认继承父目录权限。
- 目录层级上限由实施容量确定，不能直接把当前原型层级当成正式限制。
- 目录不能移动到自身或自己的子目录下。
- 团队空间中含子目录或资源挂载的目录不能直接删除，系统展示影响并要求先迁移或移除内容；个人空间执行 7.4 的二次确认和级联删除规则。
- 重命名和移动目录不生成资源版本，也不改变资源来源。
- 目录路径变化后，旧收藏或链接应通过目录 ID 定位，不依赖完整路径文本。

### 7.7 添加资源

添加资源采用双栏选择器：

1. 用户先选择资源类型：文件、数据表或图数据。
2. 左侧或筛选区选择知识源；右侧展示用户可发现、可挂载的资源。
3. 用户搜索并多选资源，系统展示已选数量和已存在于当前目录的状态。
4. 提交时重新校验目录编辑权、资源存在性、资源引用权和目录状态。
5. 成功后创建资源挂载关系，不复制内容、不更改来源、不触发发布或知识生产。

文件候选至少展示名称、类型、来源和更新时间；数据表和图数据展示名称、资源类型、来源和状态。已经挂载当前目录的资源禁止重复选择。

### 7.8 多目录挂载

- 同一资源可以挂载到多个团队或个人目录。
- 每条挂载关系使用目录 ID＋资源 ID 唯一约束。
- 移除一个挂载只删除当前关系，原资源、其他挂载和版本记录保持不变。
- 资源内容更新后，各目录默认指向同一资源当前版本，但下游知识生产仍保留所引用的确定版本。
- 删除资源前必须列出全部目录挂载和下游引用，不能由某个目录管理员连带删除其他目录关系。

### 7.9 自动入目

自动入目根据文件属性、标签和内容生成候选目录建议。处理完成只产生候选，不直接建立正式挂载。

业务流程：

`选择资源范围 → 生成目录候选 → 展示候选路径与理由 → 用户保留／调整／跳过 → 校验目录及权限 → 确认挂载 → 更新任务结果`

每条建议保存资源 ID、资源版本、候选目录 ID、目录树修订号、建议理由和处理状态。没有合适目录时显示“未匹配”，不自动创建目录。候选目录在确认前被删除或权限发生变化时，该项失效并要求重新选择。

批量确认必须明确所选数量。重复确认不得创建重复挂载；已经存在的关系显示“已在目录”。

### 7.10 目录权限

| 操作 | 查看成员 | 编辑成员 | 管理成员 |
| --- | --- | --- | --- |
| 浏览目录结构 | 是 | 是 | 是 |
| 查看挂载资源 | 另校验资源查看权 | 另校验资源查看权 | 另校验资源查看权 |
| 添加／移除挂载 | 否 | 是 | 是 |
| 新建子目录 | 否 | 是 | 是 |
| 修改目录属性 | 否 | 按产品配置 | 是 |
| 移动／删除目录 | 否 | 否 | 是 |
| 管理成员与权限 | 否 | 否 | 是 |
| 修改资源内容 | 否 | 另校验资源编辑权 | 另校验资源编辑权 |

目录支持用户、用户组和组织机构作为授权主体。权限详情显示权限级别和来源：当前目录、继承父目录或资源单独授权。

建议权限继承使用动态规则。继承项应到来源目录修改，不能在子目录直接删除。若本期开放“停止继承”，必须提前展示受影响成员和资源，且仅允许管理成员执行。

### 7.11 空间可见与资源可用

全员可见表示用户可以发现团队空间或目录入口，不代表所有挂载资源都可以无条件读取。通过某个目录访问资源，需要同时满足：

1. 用户对当前目录具有访问权；
2. 用户对资源内容具有相应查看、下载或编辑权；
3. 源系统权限和密级等强限制允许该操作。

目录挂载默认不扩大资源授权。如产品提供“添加资源时同时授权目录成员”，必须由具有资源授权能力的人显式选择，并展示授权范围和影响。

### 7.12 资源目录详情

从资源目录进入资源详情时，页面展示资源信息及当前目录上下文：当前目录路径、目录权限来源、当前挂载创建人和挂载时间。页面可以维护当前目录或资源的授权，但不能出现“正式发布版本”等知识资产发布文案。

目录详情与文件中心详情引用同一个资源和版本数据。属性、标签和内容不能因为入口不同而出现两份独立状态。

### 7.13 主要异常

| 异常 | 处理要求 |
| --- | --- |
| 同级目录重名 | 阻止保存并定位名称字段 |
| 删除非空目录 | 展示子目录和挂载数量，要求先处理内容 |
| 目标目录已删除 | 阻止挂载或移动，刷新目录树 |
| 用户权限已变化 | 重新鉴权，保留未提交选择并提示 |
| 资源已被删除 | 不创建挂载，返回逐项失败结果 |
| 批量挂载部分失败 | 成功项保留，失败项说明原因并允许重试 |
| 自动入目目录修订冲突 | 使候选失效，要求重新选择而不是按同名猜测 |
| 团队负责人失效 | 空间进入治理待办，指定有权管理员处理移交 |

### 7.14 模块输出

- 团队空间和个人空间。
- 目录树、目录节点及其修订。
- 目录成员、角色、继承和附加授权。
- 资源挂载关系和自动入目确认结果。
- 面向知识生产的授权目录范围。

### 7.15 重点验收

- 团队空间和个人空间只出现在资源目录管理下。
- 个人空间添加资源时，从文件中心已有资源中选择，不重复上传内容。
- 同一资源挂载两个目录后移除一个，另一关系和原资源保持。
- 目录管理员无资源内容权时不能预览或编辑文件。
- 删除非空目录被阻止并显示影响。
- 自动入目未确认前目录中不存在新增关系。
- 资源目录详情无发布、已发布、正式发布版本等文案。

## 8. 模块四：数据表

### 8.1 模块定位

数据表模块统一登记从关系数据库和数据仓库接入的表、视图及字段结构，为资源目录组织和知识生产提供结构化数据输入。本模块默认只读，不承担源库数据编辑、任意 SQL 查询和业务指标建模。

### 8.2 页面结构

- 左侧按结构化知识源实例展示全部数据源和各来源表数量。
- 右侧展示当前来源的表和视图列表。
- 支持按名称、描述、负责人和更新时间筛选。
- 空来源显示“尚未同步结构信息”及跳转知识源管理入口。

### 8.3 列表字段

| 字段 | 规则 |
| --- | --- |
| 数据表名称 | 使用库／Schema／表的完整身份避免重名 |
| 描述 | 优先源端注释，允许有权用户补充业务描述 |
| 数据源 | 知识源实例名称 |
| 对象类型 | 表或视图 |
| 数据规模 | 明确精确值、估算值或未知，并显示统计时间 |
| 负责人 | 来源负责人或业务负责人 |
| 最后更新时间 | 结构或数据刷新时间，需标明具体口径 |
| 状态 | 正常、结构同步中、同步失败、无权读取等 |

### 8.4 数据表详情

1. 基本信息：知识源、数据库、Schema、对象名、对象类型、描述、负责人和更新时间。
2. 字段结构：字段名、类型、长度、是否可空、主键、注释和敏感标记。
3. 样本预览：仅在权限和安全规则允许时展示有限、脱敏的数据样本。
4. 业务属性：业务域、使用场景、数据口径、更新频率和责任部门。
5. 结构版本：新增字段、删除字段、类型变化和描述变化。
6. 目录引用与下游使用：有权查看的目录挂载、知识生产任务和影响对象。

### 8.5 接入和更新规则

- 表结构同步、数据副本同步和实时查询是三种不同能力，知识源配置必须说明实际模式。
- 如果本期只同步结构，页面不能用“已同步”暗示全表数据已保存。
- 不为展示列表默认执行全表扫描；规模可以使用来源统计信息或估算值。
- 表或视图身份使用知识源 ID、数据库、Schema 和源对象 ID 组合，不只用表名。
- 结构变化生成新的结构版本并保留差异。
- 删除表或缩小同步范围时先标记源端不可用，保留下游影响关系。
- 样本预览与结构查看权限分离；能够查看字段结构不等于能够读取行数据。
- 敏感字段按策略脱敏，导出需单独授权和审计。

### 8.6 添加到资源目录

数据表可以被挂载到团队空间或个人空间的目录节点。挂载不复制数据，也不自动授予数据读取权。目录成员查看样本时仍需满足数据表内容权限和行列安全规则。

### 8.7 主要异常

- 来源认证失败：显示来源异常，不使用旧状态冒充本次同步成功。
- 表已删除：保留历史结构和影响清单，停止新加工任务使用当前资源。
- 字段类型变化：标记不兼容风险并提示下游任务。
- 大表行数未知：显示未知，不执行高成本统计。
- 无样本权限：仍可在允许时查看结构，但不返回受限值。

### 8.8 模块输出

- 表／视图资源及结构版本。
- 字段结构、业务描述和安全标记。
- 受权样本预览能力。
- 目录挂载和下游引用关系。

### 8.9 重点验收

- 选择数据源后只显示该来源对象。
- 表结构、数据副本和实时查询状态表达清楚。
- 无行数据权限的用户不能通过预览、导出或接口获得样本。
- 字段变化生成结构差异并提示受影响任务。

## 9. 模块五：图数据

### 9.1 模块定位

图数据模块负责纳管外部图数据库或图文件中的原始节点集、边集合和属性结构。它描述原始图数据，不承担企业语义模型设计、实体融合、关系审核和语义知识图谱发布。

### 9.2 页面结构

- 左侧展示图数据源实例。
- 右侧展示节点集、边集合或节点与边组合数据集。
- 支持按名称、数据类型、状态和更新时间筛选。
- 列表展示名称、类型、来源、规模、最近同步、状态和操作。

### 9.3 图数据详情

| 区域 | 内容 |
| --- | --- |
| 基本信息 | 来源、图空间、数据集名称、负责人、同步方式和更新时间 |
| 节点结构 | 节点标识、标签／类型和属性字段 |
| 边结构 | 起点字段、终点字段、关系类型和属性字段 |
| 样本 | 权限允许的有限节点和边示例 |
| 质量检查 | 唯一标识缺失、孤立边、重复边、非法空值、类型冲突 |
| 版本与影响 | 结构变化、目录挂载和下游知识生产引用 |

### 9.4 接入类型

当前原型出现 Neo4j、JanusGraph 和图文件三类扩展来源。它们与通用知识源目录中的九类连接器范围尚未完全统一，第二版将其作为图数据模块候选能力，不直接承诺首期全部生产可用。

图文件至少需要明确：节点文件、边文件、节点主键、边起点、边终点、关系类型、编码、分隔符和错误处理策略。仅提供一个压缩包地址不足以形成稳定产品能力。

### 9.5 业务规则

- 图数据使用稳定的数据集 ID 和结构版本，不以展示名称唯一识别。
- 规模分别记录节点数和边数，不合成无解释的总条目数。
- 同步过程校验节点标识唯一性、边端点有效性和字段类型。
- 无效项进入错误清单；部分成功是否允许入库需按来源策略配置并明确展示。
- 原始图标签不自动等同于平台本体概念或语义实体类型。
- 原始图接入后如需构建语义图谱，必须进入知识生产完成映射、融合、审核和资产发布。

### 9.6 权限与安全

图结构查看、样本查看、批量导出和下游使用分别授权。目录挂载不扩大图数据权限。错误清单可能包含敏感标识，同样需要权限过滤和审计。

### 9.7 模块输出

- 原始图数据集、节点／边结构及版本。
- 质量检查结果和失败项。
- 目录挂载与下游引用。
- 可供知识生产使用的确定数据集版本。

### 9.8 重点验收

- 页面明确显示原始图数据，不使用“语义知识图谱已构建”的表达。
- 无效边可定位，不能全部显示成功。
- 结构版本变化能够提示下游影响。
- 用户只有目录查看权时，仍不能绕过图数据授权查看样本或导出。

## 10. 模块六：标签管理

### 10.1 模块定位

标签管理聚合文件中心中由自动处理和用户补充的文件标签，支持标签分类、关联文件查询和标签治理。标签用于描述和筛选资源，不承担目录组织和权限控制。

### 10.2 页面结构

页面保持左右布局：

- 左侧展示标签分类、标签名称、关联文件数和搜索入口。
- 右侧展示当前标签的关联文件列表。
- 提供标签分类管理和将标签加入分类的操作。
- 窄屏时保留左右关系，通过局部滚动处理，不直接改为上下布局。

### 10.3 标签来源和状态

| 来源 | 说明 | 生效建议 |
| --- | --- | --- |
| AI 自动生成 | 元数据补充任务产生，保存任务、结果版本和依据 | 待人工确认后进入正式筛选 |
| 规则生成 | 根据来源或内容规则产生 | 按规则可信等级决定是否需确认，首期建议确认 |
| 人工补充 | 有权用户在文件详情中新增 | 保存操作者和时间，可直接生效 |

自动标签与属性结果在同一次“元数据补充”任务中产生，对外不再提供单独“自动打标”任务类型。

### 10.4 标签聚合规则

- 标签与文件资源版本关联。同一资源挂载多个目录，不重复增加关联文件数。
- 标签名称、数量和关联文件均执行权限过滤，不能从数量推知无权文件存在。
- 标签名称去除首尾空格，比较时统一全角半角；大小写处理按语言和业务场景配置。
- 文件新版本的标签需要重新处理或人工确认，旧版本标签保留历史记录。
- 未确认候选标签和已确认有效标签在页面中使用不同状态。

### 10.5 标签分类

标签分类只用于整理标签。将标签加入分类不会移动文件、改变文件标签、创建目录挂载或修改权限。

支持新建、修改和删除分类。删除分类后，标签保留并进入未分类。首期建议一个标签最多归入一个管理分类；是否允许多分类列入后续评审。

### 10.6 标签治理

- 从某文件移除标签，只删除该文件与标签的关联。
- 删除全局标签前展示受影响文件数并要求管理权限。
- 合并同义标签需要选择保留名称、查看影响文件和保留历史映射。
- 不依赖 AI 自动合并含义相近但业务口径不同的标签。
- 标签被下游筛选条件使用时，删除或合并前展示影响。

### 10.7 模块输出

- 标签及分类。
- 文件版本与标签的关联及来源。
- 标签关联文件的权限过滤查询。
- 标签治理变更记录。

### 10.8 重点验收

- 修改标签分类后，文件上的标签和资源目录位置不变。
- 同一资源挂载多个目录，标签关联数不重复。
- 低权限账号看不到无权文件的标签统计。
- 历史自动打标任务在任务中心归入“元数据补充”。

## 11. 模块七：任务中心

### 11.1 模块定位

任务中心是资源纳管所有异步操作的长期记录、异常处理和人工确认入口。右上角消息中心只展示任务进度和结果摘要，不承担完整的任务查询和操作。

### 11.2 任务类型（已明确）

| 任务类型 | 触发入口 | 主要结果 | 人工确认 |
| --- | --- | --- | --- |
| 文件上传 | 文件中心 | 文件资源和初始版本 | 上传结果无需确认；属性结果另确认 |
| 知识源同步 | 知识源管理或计划调度 | 新增、更新、失败和跳过资源 | 同步本身无需确认 |
| 元数据补充 | 文件中心或知识源功能 | 业务属性、管理属性和标签建议 | 逐文件确认 |
| 自动入目 | 文件中心、知识源或资源目录 | 资源与候选目录关系 | 确认后建立挂载 |

历史“连接器同步”统一归入“知识源同步”；历史“自动打标”归入“元数据补充”，但保留原始类型、结果和审计信息。

### 11.3 任务列表

列表字段包括任务名称和编号、任务类型、资源来源、发起人、开始时间、进度或结果、执行状态、待确认状态和操作。

支持按关键词、任务类型、执行状态、发起人、来源和时间筛选。任务名称和“查看”操作进入同一个详情路由。执行已完成但仍有待确认项时，应显示“执行完成，待确认 N 项”，不能仅显示“已完成”。

### 11.4 任务执行状态

| 状态 | 含义 | 可用操作 |
| --- | --- | --- |
| 排队中 | 已受理，尚未开始 | 查看、符合条件时取消 |
| 执行中 | 正在处理任务项 | 查看进度、申请取消 |
| 部分成功 | 成功和失败项同时存在 | 查看结果、审核成功项、重试失败项 |
| 已完成 | 所有任务项正常结束 | 查看结果；按任务类型进入确认 |
| 执行失败 | 无可用成功结果或任务级失败 | 查看原因、按条件重试 |
| 取消中 | 已提交取消，执行器尚未结束 | 查看 |
| 已取消 | 后续项目已停止 | 查看已成功和未执行项 |

当前原型未完整实现部分成功、取消中和服务恢复，这些属于后端阶段要求。

### 11.5 任务数据规则

- 任务保存提交范围快照、实际处理对象、发起人、参数、资源版本和处理规则／模型版本。
- 每个任务项对应一个准确资源版本，并保存状态、处理次数、结果和错误。
- 重复提交使用幂等键。相同来源、范围和执行目的已有任务时，系统提示查看已有任务或明确创建新轮次。
- 已完成数等于已经结束的任务项数；未知总量时显示已发现或已处理数量，不显示虚假百分比。
- 重试默认只处理失败项并生成新的执行轮次，不清除历史错误。
- 取消不回滚已经成功登记的资源；页面明确展示已完成和未执行数量。

### 11.6 元数据补充任务详情

页面采用左文件列表、右审核内容的左右结构：

- 左侧展示处理文件、搜索、当前选择和逐文件确认状态。
- 右侧展示业务属性、管理属性、标签、原建议和真实依据。
- 支持保存修改和确认当前文件。
- 切换文件时保存草稿；保存失败时不允许静默丢失。
- 刷新页面后恢复已经持久化的草稿和确认状态。

允许审核的基础条件是：任务属于元数据补充、对应任务项已成功并且存在逐文件结果。执行中、失败或没有真实结果时，只显示状态说明，不生成可确认表单。

设计建议允许部分成功任务中的成功项先审核，失败项独立重试。确认时校验资源版本、结果修订号、用户权限和字段要求。

### 11.7 自动入目任务详情

详情展示文件、候选目录完整路径、建议理由、匹配结果和处理状态。用户可以接受候选、选择其他有权目录或跳过。

确认时再次校验资源、目标目录、目录修订和用户权限。成功项建立幂等挂载，失败项返回逐项原因。目标目录重名时使用目录 ID 和完整路径，不按名称猜测。

### 11.8 通知规则

- 任务开始后可在消息中心显示进行中摘要。
- 完成、失败或需要人工确认时通知发起人和配置的负责人。
- 多文件任务聚合通知，不为每个文件产生大量重复消息。
- 通知已读状态与任务执行、确认状态相互独立。
- 点击通知进入任务详情或带筛选的任务中心。

### 11.9 服务恢复和异常

- 任务服务重启后根据持久化任务和任务项恢复，不依赖浏览器页面继续打开。
- 外部来源限流使用退避和检查点续传。
- 认证失败停止无意义重试，要求更新知识源凭据。
- 已撤权用户不能继续查看任务结果或确认资源；由有权负责人接手。
- 保存审核草稿失败时保留页面输入并提示重试。
- 旧任务结果对应的资源版本已经变化时标记“结果过时”，禁止覆盖新版本。

### 11.10 模块输出

- 任务、执行轮次和任务项。
- 进度、失败原因、重试与取消记录。
- 逐文件属性、标签和自动入目结果。
- 草稿、人工确认和审计记录。

### 11.11 重点验收

- 任务类型只有文件上传、知识源同步、元数据补充、自动入目四类。
- 历史自动打标数据归类后结果不丢失。
- 任务执行完成和业务确认完成分别表达。
- 无真实逐文件结果时不显示虚假审核表单。
- 两人同时确认时检测修订冲突。
- 服务重启和重复重试不会重复创建资源、标签或挂载。

## 12. 模块八：知识源管理

### 12.1 模块定位

知识源管理用于配置平台如何访问外部文件系统、协作系统、数据库、数据仓库和图数据源，并管理连接状态、接入方式、范围、同步计划和异常。连接配置与资源处理分离。

### 12.2 连接器范围

当前通用连接器目录包括：Confluence、S3、Oracle、Jira、GitLab、GitHub、MySQL、PostgreSQL、Hive。图数据原型还出现 Neo4j、JanusGraph 和图文件，作为候选扩展能力单独评审。

| 资源类型 | 典型连接器 | 进入模块 |
| --- | --- | --- |
| 文件 | Confluence、S3、Jira、GitLab、GitHub | 文件中心 |
| 数据表 | MySQL、PostgreSQL、Oracle、Hive | 数据表 |
| 图数据 | Neo4j、JanusGraph、图文件 | 图数据 |

任务示例中出现的飞书和 Wiki 只是历史原型数据，不能据此认定为正式支持类型。

### 12.3 知识源实例列表

列表展示实例名称和类型、连接状态、同步状态、接入方式、接入范围摘要、刷新频率、最近执行、负责人和操作。连接状态与同步状态分别展示。

可用筛选包括全部、正常、需处理、已停用，以及类型和负责人。实例统计从服务端返回，不使用页面固定数量。

### 12.4 新建知识源

流程：

`选择连接器类型 → 填写连接信息 → 选择直连／同步 → 设置负责人和范围 → 测试连接 → 保存实例 → 启动登记或同步`

通用字段如下：

| 字段 | 规则 |
| --- | --- |
| 实例名称 | 必填，建议在租户范围唯一 |
| 连接器类型 | 必填，保存后不直接更换类型 |
| 地址／端点 | 按类型校验协议、主机、端口和路径 |
| 认证方式 | 按连接器动态选择 |
| 凭据 | 不明文回显；编辑留空表示保留原凭据 |
| 接入方式 | 直连或同步，并明确内容是否保存 |
| 负责人 | 必填，用于异常处理和变更确认 |
| 接入范围 | 空间、项目、仓库、桶路径、库表、图空间等 |
| 同步频率 | 同步方式适用，显示时区和下次执行时间 |
| 备注 | 说明用途和限制 |

### 12.5 连接参数

### 12.6 测试连接

测试连接需要验证：网络可达、身份认证成功、目标范围存在、具备所需读取权限和连接器版本兼容。测试结果显示时间、测试范围和失败原因。

修改连接地址、凭据、类型、访问模式或接入范围后，原测试结果失效，需要重新测试。仅修改备注等不影响连接的字段可以保留测试结果。

测试连接成功只说明连接可用，不代表文件、表或图数据已经登记或同步。

### 12.7 直连与同步（已明确）

| 维度 | 直连 | 同步 |
| --- | --- | --- |
| 内容副本 | 不在平台长期保存完整内容副本 | 在平台保存同步内容或结构副本 |
| 登记信息 | 保存来源标识、技术信息、权限映射和版本标识 | 同时保存登记信息和内容版本 |
| 内容访问 | 使用时访问远端 | 访问平台保存的当前同步版本 |
| 立即同步 | 不显示 | 有权限时显示 |
| 远端不可达 | 当前内容不可用，并说明原因 | 可按策略使用最近副本并提示同步时间 |
| 新版本发现 | 重新访问或读取远端版本标识 | 按计划或手动同步发现 |
| 知识生产 | 需解决版本固定和证据复现 | 引用平台保存的确定版本 |

直连不保存完整正文，但可以保存必要的资源登记信息。临时预览缓存、AI 派生内容和下游加工产物是否保存，需要按照安全和合规要求逐项确定，不能用“直连”概念一并模糊处理。

### 12.8 同步规则

- 首次同步先枚举范围，再逐项读取，显示发现、成功、失败和跳过数量。
- 增量同步优先使用来源版本号、修改时间、游标或校验摘要。
- 同一远端对象同一版本重复执行保持幂等，不重复创建资源。
- 远端重命名保留资源身份；远端对象 ID 改变时按新对象处理并提示可能关联。
- 远端删除先标记“源端已删除”，保留目录挂载和下游影响查询，不静默级联删除。
- 缩小范围标记资源“不再同步”，不直接当作业务删除。
- 暂停同步只阻止后续调度；执行中任务通过单独取消动作处理。
- 同一实例和范围默认避免并发重复同步。
- 同步默认只从源端读取，不回写源系统内容。

### 12.9 编辑、停用和删除

编辑地址、范围或接入方式前展示影响。同步转直连需要确定已有副本如何处理；直连转同步需要说明新增存储和权限影响，两者不作为无提示的普通单选修改。

停用知识源保留实例、历史资源和任务，停止后续调度。删除前检查执行中任务、资源、目录挂载和下游引用；存在引用时优先停用。即使最终删除配置，历史资源仍需保留来源快照和审计信息。

### 12.10 权限和安全

- 创建和编辑知识源需要功能权限及对应管理范围。
- 凭据使用安全引用保存，不进入页面源代码、日志、导出和审计详情。
- 使用技术账号能够读取远端内容，不代表所有平台用户都有内容访问权。
- 直连资源需要处理源端用户 ACL 映射；无法映射时不得宣称已经继承源端权限。
- 连接目标需要限制网络访问范围，避免配置任意内部地址造成安全风险。
- 每次凭据修改、范围变更、测试、同步、停用和删除均记录审计。

### 12.11 模块输出

- 知识源实例和安全凭据引用。
- 连接、认证和同步状态。
- 接入模式、范围和同步计划。
- 文件、数据表或图数据接入任务。
- 来源与资源之间的稳定追溯关系。

### 12.12 重点验收

- 连接状态和同步状态分开显示。
- 切换直连／同步后连接测试失效并需重新验证。
- 直连来源无“立即同步”，且不长期保存完整内容副本。
- 连接成功但未同步时，文件中心不出现已同步资源。
- 远端删除不静默删除目录挂载或已发布知识资产。
- 凭据不明文回显，也不出现在日志和错误信息中。

## 13. 跨模块权限设计

### 13.1 权限层次

权限至少包含四层：

1. 功能权限：能否进入资源纳管菜单和使用页面按钮。
2. 目录权限：能否查看、编辑或管理某团队／个人目录。
3. 资源权限：能否查看、下载、更新、删除或授权某个资源。
4. 来源与安全限制：源端 ACL、数据密级、禁止外传、行列权限等强限制。

系统功能权限按照“一级菜单 → 二级菜单 → 页面按钮”组织。用户默认继承组织功能权限，并可以有额外授权。功能权限只决定能否发起操作，不能代替服务端对象权限判断。

### 13.2 权限计算建议

- 同一用户的有效允许权限取操作并集。
- 停用账号、密级、禁止外传和源端拒绝等强限制优先。
- 首期如不实现显式拒绝授权，界面不应展示无法解释的拒绝优先级。
- 多目录挂载不自动扩大资源权限。
- 通过目录访问资源时，需要目录访问权和资源相应内容权限同时成立。
- 权限来源必须可解释：组织默认、用户额外、团队角色、目录继承、资源单独授权或源端映射。

### 13.3 权限变更生效

撤权后列表、搜索、标签统计、预览、下载、导出、任务结果和旧链接都需要重新鉴权。缓存需要在约定时间内收敛。后台任务开始、读取资源和提交结果时分别检查权限，不能只在创建任务时检查一次。

### 13.4 审计范围

需要审计的操作包括：知识源创建和凭据变更、同步范围变化、文件上传和版本更新、预览敏感资源、下载、导出、删除、属性和标签确认、目录和成员变更、授权和撤权、自动入目确认及知识生产引用。

审计保留操作者、时间、对象、操作、结果、变更前后摘要和追踪编号。敏感凭据和受限原文不进入审计正文。

## 14. 与知识生产的衔接

### 14.1 输入选择

知识生产从资源纳管选择已经登记的文件、数据表或图数据。用户可以按知识源、资源目录、标签和属性筛选，但提交任务时需要固定资源 ID 和版本。

建议资源进入知识生产的基础条件包括：

- 当前版本内容可访问；
- 格式或结构可被目标加工流程处理；
- 发起人拥有资源使用权和知识生产功能权限；
- 必要属性已补充；
- 关键场景下属性和标签已经人工确认；
- 未被过期、禁止使用或安全策略拦截。

是否允许未确认资源进入某些低风险加工流程，可以由知识生产流程配置，但页面需要明确提示，不把“已纳管”“已入目”“已确认”和“可加工”混为一个状态。

### 14.2 版本与证据

知识生产保存所使用的资源版本、来源、权限快照、证据定位和处理时间。文件、表结构或图数据更新后产生新版本和变更事件，不自动覆盖正在使用或已经发布的知识成果。

下游负责人查看影响清单后决定是否重新加工、审核并发布知识库或语义知识图谱的新版本。资源纳管本身不承担知识资产发布。

### 14.3 权限传递

将资源用于知识生产不自动扩大资源或成果的使用权限。知识生产和知识资产发布需要根据来源限制、目录范围、资源授权和成果用途重新计算可用范围。直连资源无法固定版本或证明源端权限时，应阻止进入要求可复现证据的正式流程。

## 15. 统一状态与业务事件

### 15.1 状态模型

| 对象 | 状态集合 |
| --- | --- |
| 知识源连接 | 待验证、已连接、认证失败、连接异常、已停用 |
| 知识源同步 | 未执行、排队中、同步中、已完成、部分成功、同步失败、已暂停 |
| 资源内容 | 可用、来源不可达、源端已删除、不再同步、已逻辑删除 |
| 文件解析 | 待解析、解析中、成功、失败、不支持 |
| 属性和标签补充 | 待处理、处理中、成功、失败、结果过时 |
| 人工确认 | 不适用、待确认、草稿、已确认 |
| 自动入目 | 待处理、待确认、已采纳、已调整、已跳过、已失效 |
| 任务执行 | 排队中、执行中、部分成功、已完成、执行失败、取消中、已取消 |
| 目录挂载 | 有效、目标目录失效、资源失效、已移除 |

列表可以显示组合后的主状态，但底层状态必须独立存储。例如“待确认”不能覆盖“解析成功”和“属性补充成功”的历史事实。

### 15.2 关键状态迁移

| 事件 | 原状态 | 新状态 | 规则 |
| --- | --- | --- | --- |
| 文件上传成功 | 未登记 | 可用＋待解析 | 生成资源和初始版本 |
| 文件解析成功 | 解析中 | 解析成功 | 保存对应版本解析结果 |
| 补充任务成功 | 处理中 | 补充成功＋待确认 | 必须有真实逐文件结果 |
| 保存修改 | 待确认／已确认 | 草稿 | 原确认记录保留 |
| 确认当前结果 | 待确认／草稿 | 已确认 | 校验版本、修订和权限 |
| 内容版本更新 | 旧版本已确认 | 新版本待处理 | 旧版本结果保持可追溯 |
| 自动入目完成 | 处理中 | 待确认 | 尚未建立挂载 |
| 采纳候选 | 待确认 | 已采纳 | 幂等创建挂载 |
| 来源对象删除 | 可用 | 源端已删除 | 保留影响和历史引用 |
| 任务请求取消 | 排队／执行中 | 取消中／已取消 | 已成功项不自动回滚 |

### 15.3 业务事件

建议提供以下事件：知识源已连接、知识源异常、资源登记完成、资源版本新增、解析失败、属性与标签补充完成、结果已确认、自动入目已采纳、目录授权变更、源端资源删除、资源逻辑删除和下游引用变化。

事件包含对象 ID、版本、发生时间、操作者或任务、租户和追踪编号。消费者需要支持幂等和失败重放。

## 16. 数据设计建议

### 16.1 核心记录

| 记录 | 最小字段 | 关键约束 |
| --- | --- | --- |
| Source | id、type、name、owner、access_mode、credential_ref、scope、status | 凭据只保存安全引用 |
| Resource | id、kind、name、source_id、external_id、owner、current_version_id、status | 来源对象身份唯一 |

| DirectorySpace | id、type、name、owner、visibility、revision | type 仅为 team 或 personal |

### 16.2 一致性要求

- 所有详情、列表、任务、标签和目录使用稳定 ID，不使用文件名作为关联键。
- 文件详情和任务详情读取同一属性、标签与确认记录。
- 草稿和已确认值分开存储，保存失败不能显示已确认。
- 内容版本不可变；更新创建新版本。
- 目录挂载、确认和授权变更支持并发修订检查。
- 权限变化同步影响查询、搜索索引、缓存和下载服务。
- 逻辑删除保留必要历史和引用，物理清理由保留策略决定。

## 18. 非功能与安全要求

### 18.1 性能目标建议

以下数值为研发评估起点，最终需要结合实际部署和数据规模确认：

| 项目 | 建议目标 |
| --- | --- |
| 常规列表和筛选 | 约定负载下 P95 不超过 2 秒，包含权限过滤和分页 |
| 属性保存和确认 | 约定负载下 P95 不超过 2 秒，包含审计和并发检查 |
| 任务创建 | P95 不超过 3 秒返回受理结果，不等待任务完成 |
| 进度展示 | 正常条件下与服务端状态延迟不超过 5 秒 |
| 权限撤销 | 内容读取立即重新鉴权；列表和索引在约定时间内收敛 |
| 批量处理 | 分页枚举、逐项结果、失败可重试，不依赖一次大事务 |

文件解析、同步和 AI 处理时长按来源、文件类型和规模分别统计，不统一承诺秒级完成。最大文件、批量数量、表规模、图规模和并发任务配额在上线前形成容量表。

### 18.2 安全要求

- 所有内容查询和操作由服务端鉴权。
- 知识源凭据加密或通过密钥服务保存，不明文回显。
- 下载地址短期有效，撤权后不能依赖长期静态链接继续访问。
- 上传和预览服务隔离处理不可信文件类型。
- 外部 AI 处理前明确允许发送的数据范围、脱敏方式和服务留存政策。
- 搜索、标签数量、概览指标和错误清单同样执行权限过滤。
- 多租户部署隔离资源、目录、任务、标签、缓存、搜索索引和对象存储。
- 删除、下载、导出、授权、来源变更和结果确认保留审计。

### 18.3 可用性和恢复

- 用户关闭浏览器后后台任务继续执行。
- 任务服务重启后可以从持久化检查点恢复。
- 同一任务或回调重复执行不产生重复资源、版本、标签、确认或挂载。
- 连接器使用统一错误分类、健康状态和版本兼容记录。
- 备份和恢复覆盖内容、元数据、目录、权限和任务之间的一致性。
- 表单错误定位到具体字段；长名称、空状态和失败状态可理解。
- 页面遵循现有 Hertz 视觉体系，统一焦点、键盘和状态反馈。

## 19. 核心业务场景

### 19.1 制度文件从知识源进入知识生产

1. 来源负责人在知识源管理创建 Confluence 实例，选择同步模式并测试连接。
2. 配置制度空间范围后启动同步，任务中心展示发现、成功和失败文件。
3. 文件中心按该知识源显示文件，不归入企业／团队／个人文件空间。
4. 资源管理员发起元数据补充，系统产生属性和标签建议。
5. 业务专家在任务详情逐文件核对证据、修改并确认。
6. 目录管理员发起自动入目或手动将文件添加到团队空间的“公司金融／对公授信”目录。
7. 授权成员通过资源目录发现文件；内容访问仍校验资源权限。
8. 知识工程师选取确定资源版本进入知识生产。
9. 源端新版本同步后，平台重新处理并提示下游影响；旧版本证据保持。

整个资源纳管流程没有资源发布操作。知识库或语义知识图谱在知识生产完成后执行自己的发布流程。

### 19.2 个人整理资源

1. 用户在文件中心上传调研报告。
2. 上传成功后文件属于统一文件资源，没有“个人空间文件”字段。
3. 用户进入资源目录管理的个人空间，新建“项目调研”目录。
4. 用户从文件中心已有资源中选择报告并添加到该目录。
5. 移除目录关系时报告仍保留在文件中心。

### 19.3 团队协作

1. 负责人创建团队空间并配置管理、编辑和查看成员。
2. 编辑成员在目录中添加已有文件和数据表。
3. 查看成员能够发现目录，但读取每项资源时仍需资源权限。
4. 同一文件可以同时挂载至“风险管理”和“制度建设”目录。
5. 移除其中一个挂载不影响另一目录和原文件。

### 19.4 批量任务部分失败

100 个文件中 97 个处理成功、3 个失败。任务详情明确显示部分成功。成功项可以进入逐文件确认，失败项保留错误并单独重试。重试不会重复生成 97 个成功文件的结果。

### 19.5 资源更新影响下游

文件或表结构出现新版本后，平台保留旧版本和使用关系，生成影响事件。知识生产负责人选择是否重新加工；已经发布的知识资产不被资源纳管自动覆盖。
